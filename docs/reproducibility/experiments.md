# Reproducing experiments

For each experiment, record the Git commit and release, Python/platform identity, dependency constraint-file hash, model manifest and file hashes, source-corpus manifest, effective configuration and hash, random seeds, command, schema versions, and evaluation definition. Retain `effective_config.json`, the environment fingerprint, artifact manifest, stage trace, and terminal marker with the reported result.

Private corpora must be represented by non-sensitive identifiers and cryptographic hashes. A published result should use a named immutable configuration and an archived software release. Compare migrations by region IDs and counts, exclusions, source/resolved geometry, reading order, relationship graphs, serialized schemas, and representative overlay differences.
